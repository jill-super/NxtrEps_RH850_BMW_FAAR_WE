## Glossary

| Term | Meaning |
| --- | --- |
| ASW | Application Software (AUTOSAR layer) |
| BAC | BMW AUTOSAR Core (BMW platform modules) |
| BSW | Basic Software (AUTOSAR layer) |
| CDD | Complex Device Driver |
| DaVinci | Vector configuration/authoring tooling (Developer / Configurator) |
| DPA/Dcf | DaVinci project/configuration files (`tools/*.dpa`, `autosar/*.dcf`) |
| ECU | Electronic Control Unit |
| EPS | Electric Power Steering |
| FAAR WE | BMW front-drive architecture platform variant |
| MCAL | Microcontroller Abstraction Layer |
| MDD | Module Design Document (per-module `*_MDD.doc(x)`) |
| MICROSAR | Vector's AUTOSAR basic-software product line |
| NTC | Non- trouble-code? — here: Nexteer Trouble Code (diagnostic fault identifier used by `ES101A_DiagcMgr`) |
| RTE | Runtime Environment |
| SW-C | Software Component |
