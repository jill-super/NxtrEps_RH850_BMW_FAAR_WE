## Project overview

Complete Electric Power Steering (EPS) firmware for the **BMW FAAR WE**
platform: precise power-assisted steering control, electric-motor power
management and communication security on a **Renesas RH850/P1x**
microcontroller, developed to **AUTOSAR** and **ISO 26262 ASIL D**.

- **211 documented software modules** organised by AUTOSAR layer.
- **Third-party vs in-house code is labelled on every page**:
  Vector MICROSAR, BMW BAC, Renesas MCAL, or Nexteer custom logic
  (see the [origin guide](general/origin-guide/)).
- **Word/PDF sources converted**: per-module design documents (MDD),
  integration manuals, Vector Technical References and release notes are
  published as searchable excerpts linked from each module page
  ([full inventory](general/doc-inventory/)).

## Conventions used in this site

- Each module page states its **AUTOSAR layer**, **origin badge**
  (Vector / BMW / Renesas / Custom), key files, public API excerpt,
  dependencies and converted documents.
- Converted excerpts are capped and lose exact layout/diagrams; the
  repository sources remain authoritative (linked from every page).
- Assumptions made while documenting are stated inline as such.
